# Проект: PlaylistMaker

## Обзор
Содержание:
* Описание
* Функциональность
* Технологии

### Описание:
Приложение на android для прослушивания промо музыки в iTunes.

### Функциональность:
- можно выполнять поиск по музыке в сервисе ITunes, последние прослушанные песни будут сохраняться в истории (её можно очистить)
- при открытии плеера каждый трек можно прослушать или добавить трек в избранные/плейлисты
- в отдельной вкладке меню можно просмотреть сохраненные в избранные песни и плейлисты. Там же можно создать/удалить плейлист
- в окне плейлиста можно его редактировать
- в окне настроек можно сменить стиль на ночной

### Технологии:
язык Kotlin, минимальный SDK 33, библиотека для работы с изображениями glide(4.16.0), библиотека для работы с com.google.code.gson:gson(2.10) и com.squareup.retrofit2:converter-gson (2.9.0), библиотека для работы с com.squareup.retrofit2:retrofit(2.11.0), библиотека по жизненному циклу lifecycle-viewmodel-ktx(2.5.1), библиотека DI koin(3.3.0), библиотека корутин org.jetbrains.kotlinx:kotlinx-coroutines-android(1.3.9), библиотека БД room (2.6.1)
